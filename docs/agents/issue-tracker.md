# Issue Tracker: Local Markdown

Issues and tasks for this repository are tracked as markdown files under the .scratch/ directory.

## Conventions

- **Issue Location**: .scratch/<feature-or-topic>/ or .scratch/<issue-id>.md
- **Format**: Standard markdown describing the task, goals, requirements, acceptance criteria, and status.
- **Workflow**: Agents reading or creating tickets will read from and write markdown files directly in .scratch/.
